**[Visit ShipYard](https://mdfarhanks.github.io/shipyard/)**

## Features

- Responsive product catalog
- Product detail pages
- Static site generation
- Optimized product images
- Loading state
- Error handling
- Custom not-found page
- GitHub Pages deployment

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React
- GitHub Actions
- GitHub Pages

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/mdfarhanks/shipyard.git
   ```

2. Navigate into the project:

   ```bash
   cd shipyard
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000 in your browser.

## Deployment

ShipYard is deployed to GitHub Pages using GitHub Actions and Next.js static export.
